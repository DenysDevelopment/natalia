# Natalia Rudnik — лендинг

Односторінковий сайт для **Наталії Рудник** — майстра Рейкі та провідниці
жіночих практик. Сеанси Рейкі, авторські медитації та коучинг цілей.

Увесь сайт зібрано в один самодостатній файл — **`index.html`** (CSS, JavaScript
та зображення вбудовані). Жодних залежностей, окрім Google Fonts.

## Можливості

- 🇺🇦 / 🇵🇱 — перемикач мови (українська / польська), стан зберігається в `?lang=`
- Скрол-ефекти: parallax, «приклеєні» (sticky) колонки, поява секцій при скролі
- Адаптив — десктоп і мобільний (бургер-меню)
- SEO: мета-теги, Open Graph, Twitter Card, JSON-LD (Schema.org), `sitemap.xml`, `robots.txt`
- Доступність: семантична розмітка, `prefers-reduced-motion`, skip-link

## Структура

| Файл | Призначення |
|------|-------------|
| `index.html` | Увесь сайт — самодостатній файл |
| `robots.txt` · `sitemap.xml` | SEO-службові файли |
| `assets/` | Вихідні фото (в `index.html` вони вже вбудовані) |

## Деплой

Достатньо `index.html`. Для GitHub Pages — увімкніть Pages у Settings репозиторію.

> **Перед продакшеном:** замініть домен-заглушку `nataliarudnik.com`
> на справжній у `index.html` (canonical, Open Graph, JSON-LD), `sitemap.xml`
> та `robots.txt`. Також підключіть справжні Calendly / форму підписки.
