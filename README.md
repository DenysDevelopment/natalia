# Natalia Rudnik — лендинг

Односторінковий сайт для **Наталії Руднік** — провідника Рейки та автора
трансформаційних проектів. Сеанси Рейки, розстановки, авторські курси,
мініпродукти та медитації.

## Деплой

Деплоїться один файл — **`index.html`**: самодостатній, з вбудованими CSS, JS
та фото. Жодних залежностей, окрім Google Fonts. Для GitHub Pages — увімкніть
Pages у Settings репозиторію.

## Джерело та збірка

`index.html` — це **зібраний** файл. Редагувати зручніше модульні джерела:

| Файл | Призначення |
|------|-------------|
| `index.src.html` | розмітка (9 секцій) |
| `styles.css` | стилі — дизайн-система, скрол-ефекти |
| `content.js` | увесь текст, UA + PL |
| `app.js` | перемикач мови, скрол, FAQ, бургер-меню |

Після правок джерел `index.html` пересобирається (інлайн CSS/JS + base64-фото).

## Структура (9 секцій)

Hero · Про мене · Послуги · Курси · Мініпродукти · Медитації ·
Відгуки та кейси · FAQ · Контакти.

## Можливості

- 🇺🇦 / 🇵🇱 — перемикач мови, стан зберігається в `?lang=`
- Скрол-ефекти: parallax, sticky-колонки, поява секцій
- Адаптив — десктоп і мобільний (бургер-меню)
- SEO: мета-теги, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`

> **Перед продакшеном:** замініть домен-заглушку `nataliarudnik.com`, додайте
> справжні ціни, посилання на соцмережі, відгуки та фото клієнтів.
